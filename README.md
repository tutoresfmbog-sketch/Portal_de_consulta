# Grupo de Equidad en Salud — Página web

Sitio web estático del **Grupo de Equidad en Salud** de la Facultad de Medicina de la Universidad Nacional de Colombia, montado sobre la plantilla institucional de la UNAL.

## Contenido
- `index.html` — página principal
- `assets/` — logotipo del grupo
- `unal/` — plantilla institucional (CSS, JS, imágenes)
- `uploads/.../fonts/` — fuentes Ancizar

## Publicar
Consulta **`instrucciones.txt`** para los pasos detallados de:
1. Subir el proyecto a GitHub
2. Publicarlo en Vercel
3. Manejar variables de entorno / secretos de forma segura

> Sitio estático: no requiere build ni servidor. En Vercel usa el preset **Other** y deja vacíos *Build Command* y *Output Directory*.
